Selected spline

Terrain brush

Hold the left mouse button to paint. Width = brush diameter, Set height = the height (Z/up value) the brush pulls the ground to. Shift = invert Raise/Lower. Alt+click = copy the ground height under the cursor into "Set height".

Tiles

The camera flies up and looks straight down. Add: click a green + slot on the left / right / top / bottom of a tile to attach a new tile. Remove: click an empty tile to delete it. When you switch to another tool, the camera flies down to the newest tile.

Go to tile

Selected object

Drag in the viewport: Move = along ground, Lift = up/down, Yaw / Roll / Bend = left/right, Pitch = up/down. Hold Shift = 15° steps.

Unity prefab name

Rename if your prefab name differs.
WASD / Q E = Pohyb po mapě
Pravé tlačítko = Otáčení kamery
Levé tlačítko = Pokládání / Výběr / Úprava objektu
R = Otáčení objektů (Shift+R o 90°)
Ctrl+D = Duplikovat, Delete = Smazat
