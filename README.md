# Sušenkov - Vývojářský program a editor map

Vítejte ve vývojářském repozitáři hry **Sušenkov** (`susenkov_devprogram`). Najdete zde nástroje, skripty a editor pro tvorbu a úpravu herního světa.

## 🛠️ Editor pro tvorbu mapy
Součástí tohoto repozitáře je **editor pro dělání mapy** do Sušenkova. Pomocí něj můžete navrhovat vlastní rozvržení a lokace pro náš herní svět.
